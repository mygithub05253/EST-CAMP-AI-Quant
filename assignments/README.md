# ✏️ assignments — 과제

부트캠프 과제를 과제 단위로 관리합니다. 운영진·강사 지침(요구사항·제한·기한)을 함께 기록해 추적성을 확보합니다.

## 폴더 규칙

과제마다 폴더를 만듭니다: `NN_과제명/`

```
assignments/
├── 01_과제명/
│   ├── README.md      # 과제 요구사항·기한·제출방법·평가기준
│   ├── solution.*     # 풀이 코드/노트북
│   └── ...
```

## 과제 README 템플릿 (각 과제 폴더에 작성)

```markdown
# 과제 N · 제목

- **출제**: 강사/운영진 이름
- **출제일 / 마감일**: 2026-MM-DD / 2026-MM-DD (KST)
- **제출 방법**: (노션/깃허브/이메일 등)

## 요구사항
- ...

## 제약·규칙
- ...

## 평가 기준
- ...

## 진행 상태
- [ ] 분석 / [ ] 구현 / [ ] 검증 / [ ] 제출
```
