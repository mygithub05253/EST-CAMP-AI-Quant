# 03 · 데이터 시각화

> 교재 시각화 파트 — matplotlib 기반 그래프 작성과 시각화 실무

## 학습 목표
- matplotlib의 Figure–Axes 구조와 시각화 4단계 흐름 이해
- 데이터 성격(추세·비교·분포·관계)에 맞는 그래프 선택
- 서브플롯·꾸미기 옵션으로 보고서 수준의 그래프 완성

## 주요 내용
- 데이터 시각화 기초: 라이브러리 개요, `plot()` 흐름, Figure·Axes, 서브플롯
- 그래프 기초: 선·막대·히스토그램·산점도·파이·박스플롯
- matplotlib 예제: 실데이터 시각화, 범례·주석·스타일, folium·복합 차트
