# 과제 관리 스킬

`assignments/` 아래에 과제별 폴더와 README를 표준 포맷으로 만들고 진행을 추적한다.

## 절차
1. 새 과제 폴더 생성: `assignments/NN_과제명/` (NN은 출제 순서 2자리)
2. 폴더 안에 `README.md`를 아래 템플릿으로 작성한다.
3. 풀이는 같은 폴더에 `solution.ipynb`/`.py` 등으로 둔다.
4. `assignments/README.md`의 "진행 중인 과제" 표에 행을 추가한다.
5. `github-flow` 스킬로 `assignment/NN-과제명` 브랜치를 파서 반영한다.
6. 제출·완료 시 대시보드(`dashboard-create`)에 기록한다.

## 과제 README 템플릿
```markdown
# 과제 N · {제목}

- **출제**: {강사/운영진}
- **출제일 / 마감일**: 2026-MM-DD / 2026-MM-DD (KST)
- **제출 방법**: {노션/깃허브/이메일 등}

## 요구사항
- ...

## 제약·규칙
- {사용 라이브러리 제한, 데이터 범위, 분량 등}

## 평가 기준
- {루브릭/배점이 있으면 명시}

## 진행 상태
- [ ] 분석  - [ ] 구현  - [ ] 검증  - [ ] 제출

## 회고
- 배운 점 / 다음에 개선할 점
```

## 추적 원칙
- 운영진·강사가 준 **규칙·기한**을 README 상단에 반드시 명시한다 (작업 대시보드 규칙 2번과 일치).
- 마감일은 KST 기준 절대 날짜로 적는다.
- 큰 과제로 규모가 커지면 `projects/`로 승격하고 README에서 링크한다.
- 진행 상태 체크박스를 갱신하고, 완료 시 대시보드·`assignments/README.md` 표를 함께 업데이트한다.
