# 📊 dashboards — 작업 진행 대시보드

세션·작업 단위의 진행 현황을 **날짜 폴더**로 버전 관리합니다. 무슨 작업을 했는지,
규칙·기한은 무엇인지, 진행률은 몇 %인지를 한눈에 볼 수 있게 기록합니다.

## 폴더 규칙

```
dashboards/
├── 2026-06-16/
│   └── progress_dashboard.html   # 해당 날짜의 작업 현황 스냅샷
├── 2026-06-17/
│   └── progress_dashboard.html
└── ...
```

- 날짜는 **KST 기준** `YYYY-MM-DD`
- 한 작업/세션이 끝날 때마다 그날 폴더에 대시보드를 생성·갱신
- 이전 날짜 대시보드는 보존(스냅샷)해 변화 추이를 추적

## 대시보드에 담는 내용 (작업 대시보드 규칙)
1. **무슨 작업**을 진행했는지 (과제/프로젝트/학습 등)
2. 운영진·강사 **규칙·요구사항·기한**
3. **진행률(%)** — 막대 차트 형태 권장
4. 실무 벤치마킹 결과를 반영한 작업 유형별 포맷 (기획/개발/과제)
