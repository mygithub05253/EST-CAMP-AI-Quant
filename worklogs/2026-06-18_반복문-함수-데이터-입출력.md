## 📝 오늘 배운 내용 요약

1. **반복문과 반복 제어** — 반복 횟수나 범위가 정해졌는지에 따라 `while`과 `for`를 구분해 사용.
    - `while`은 조건이 `True`인 동안 실행하며, 반복 횟수가 명확하지 않은 작업에 적합함.
    - `for`는 문자열·리스트·튜플·`range`·딕셔너리처럼 반복 가능한 객체를 순회할 때 사용함.
    - `break`로 반복을 종료하고 `continue`로 현재 반복의 나머지를 건너뛰는 흐름을 실습함.
    - 중첩 반복문으로 구구단과 2차원 리스트를 처리하고, `enumerate()`와 리스트 내포로 인덱스 처리와 반복 코드를 간결하게 표현함.

2. **함수의 정의와 데이터 전달** — `def`로 기능을 묶고 매개변수와 반환값을 이용해 재사용 가능한 코드를 작성.
    - `return`은 결과를 반환하는 동시에 함수 실행을 종료하며, 여러 값을 반환하면 하나의 튜플로 전달됨.
    - 디폴트 매개변수, 키워드 인수, 가변 위치 인수 `*args`, 가변 키워드 인수 `**kwargs`의 차이와 선언 순서를 익힘.
    - 지역변수와 전역변수의 탐색 범위를 비교하고, 전역값 변경 시 `global`이 필요한 이유를 확인함.
    - `chr()`·`ord()`·`eval()` 등 내장 함수의 동작을 실행 결과로 확인함.

3. **사용자 입력과 파일 입출력** — 입력값의 자료형과 파일 열기 모드에 따라 데이터를 안전하게 읽고 쓰는 흐름을 실습.
    - `input()`의 반환값은 항상 문자열이므로 계산에 사용할 때 자료형 변환이 필요함.
    - `open()`의 `r`·`w`·`a` 모드와 `readline()`·`readlines()`·`read()`의 반환 형태를 비교함.
    - 파일 작업 후 `close()`가 필요하며, `with open(...) as f`를 사용하면 파일이 자동으로 닫힌다는 점을 확인함.

4. **Day03 함수 실습**
    - 몫과 나머지를 함께 반환하는 함수에서 `/`와 형변환 대신 정수 나눗셈 연산자 `//`를 사용하는 풀이를 확인함.
    - 홀짝 판별 함수를 조건문의 불 표현식인 `num % 2 == 1`로 간결하게 반환함.
    - 커피 자판기 함수에서 메뉴 존재 여부와 결제 금액을 순서대로 검증하고, 정상 주문일 때 커피명과 잔돈을 튜플로 반환함.
