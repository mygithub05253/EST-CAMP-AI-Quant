1. **자료형 개념과 변수** — 자료(data)는 프로그램이 처리하는 모든 것, 자료형(data type)은 기능·역할에 따라 구분한 종류.
    - 변수는 메모리에 데이터를 저장하는 이름. Python은 **동적 타이핑(Dynamic Typing)** 으로 타입이 바뀔 수 있음.
    - 상수는 한 번 정하면 안 바꾸는 값. Python엔 상수 키워드가 없어 관례적으로 대문자(`PI = 3.14159`)로 표기.
    - `type()` 으로 자료형 확인 (`<class 'int'>` 처럼 출력).
2. **숫자 자료형 (int / float)** — 정수형은 소수점 없는 수, 실수형은 소수점 있는 수. `0`과 `0.0`은 크기는 같지만 자료형이 다름.
    - 지수 표현: `4.24e4 → 42400.0`, `4.24e-4 → 0.000424`.
    - 사칙연산: `+ - * /`, 추가로 `**`(제곱) · `//`(몫) · `%`(나머지).
    - 연산자 우선순위: `* /` 가 `+ -` 보다 먼저, 같은 순위는 왼→오. 헷갈림 방지로 **괄호를 명시적으로** 쓰는 게 권장.
3. **문자열 자료형 (str)** — 글자들의 나열. `" "`, `' '`, `""" """`, `''' '''` 4가지 표기법.
    - 표기법이 여러 개인 이유: ① 문자열 안에 따옴표 포함 ② 여러 줄 표현.
    - 따옴표 포함: 다른 종류 따옴표로 감싸거나 `\'` 역슬래시(escape) 사용.
    - 여러 줄: `\n`(줄바꿈)·`\t`(탭) 또는 따옴표 3개.
    - 문자열 연산자: `+`(연결), `*`(반복). 단 `"문자" + 1` 은 `TypeError` → 숫자도 `"1"` 처럼 문자열이어야 연결됨.
    - 인덱싱: `str1[0]`(0부터), `str1[-1]`(뒤에서 -1부터).
    - 슬라이싱: `str1[시작:종료]` — **종료 인덱스는 미포함**. 생략 시 처음/끝까지.
    - 포매팅 3가지: `%` 연산자(`%d %f %0.2f %05d`), `.format()`(인덱스·이름 지정), **f-string**(`f"{a}+{b}={a+b}"`).
    - 관련 함수: `count` · `find`(없으면 -1) · `index`(없으면 에러) · `upper`/`lower` · `strip` · `replace` · `len`.
4. **불 자료형 (bool)** — `True`/`False`로 명제 결과 표현.
    - 비교 연산자: `== != < > <= >=` (한글 문자열은 사전 순서로 비교).
    - 논리 연산자: `not`(반대), `and`(둘 다 참이어야 True), `or`(하나만 참이어도 True).
    - `bool()` 변환: 빈 문자열 `""`·`0`·`None` 은 `False`, 그 외는 `True`.
    - `int(True) → 1`, `int(False) → 0`.

## 💭 오늘의 회고

1. **배운 점**
    - 같은 `+` 기호라도 숫자에서는 덧셈, 문자열에서는 연결로 **자료형에 따라 연산자 동작이 다르다**는 걸 명확히 이해함.
    - 슬라이싱의 "종료 인덱스 미포함" 규칙, 인덱스가 0부터/뒤에서 -1부터 센다는 점이 헷갈렸지만 직접 출력해보며 감을 잡음.
2. **어려운 점/개선할 점**
    - 문자열 포매팅 3가지 방식(`%`, `.format()`, f-string)의 사용 시점이 아직 헷갈림 → 실무에서 가장 많이 쓰는 **f-string 위주로 손에 익히기**.
    - `find`(-1 반환)와 `index`(에러 발생)의 차이를 상황별로 언제 쓸지 더 연습 필요.
3. **액션 플랜**
    - 슬라이싱·인덱싱을 다양한 문자열로 직접 잘라보며 반복 연습.
    - 내일 **자료형 심화** 학습에 대비해 오늘 배운 기본 자료형(int/float/str/bool)을 복습하고 넘어가기.
4. **함께 나누고 싶은 점**
    - 연산자 우선순위가 확실해도 가독성을 위해 괄호를 쓰라는 팁이 인상적이었음 — 협업·디버깅 시 의도 파악에 도움.
