# 클래스 기본 · 클래스 심화 — 2026-06-19

> 날짜: 2026-06-19 · Subject: Python 기초 · title: 클래스 기본 · 클래스 심화 · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **함수 복습·보강** — 앞서 학습한 함수의 매개변수·반환 구조를 다시 실행해 동작을 점검.
    - 디폴트·키워드 인수, 가변 인수(`*args`, `**kwargs`)의 선언 순서를 재확인함.
    - 함수 단위로 기능을 나누는 사고를 클래스 학습으로 연결함.

2. **클래스와 객체 기본** — 객체를 만들기 위한 설계도가 클래스이며, 속성(변수)과 기능(메소드)을 함께 가짐.
    - 인스턴스 변수는 `self.식별자` 형태로 객체마다 별도로 저장되는 값임을 익힘.
    - 인스턴스 메소드는 첫 번째 매개변수로 `self`를 받아 자기 자신을 가리킴을 확인함.
    - 생성자 `__init__()`은 객체가 생성될 때 자동으로 호출되어 초기 속성을 설정함.

3. **클래스 심화** — 특수 메서드와 객체지향 핵심 개념(캡슐화·상속)을 실습.
    - 소멸자 `__del__()`은 인스턴스가 소멸될 때 자동 호출되며, `isinstance(객체, 클래스)`로 소속 클래스를 확인함.
    - `__str__()`, 비교 연산 메서드(`__eq__`·`__lt__`·`__gt__` 등) 같은 특수 메서드로 객체 동작을 재정의함.
    - 클래스 변수와 클래스 메서드는 객체가 아니라 클래스 자체에 속하는 값·기능임을 구분함.
    - 캡슐화: `__이름`으로 프라이빗 변수를 선언하고 getter/setter로 안전하게 접근하는 패턴을 익힘.
    - 상속으로 부모 클래스의 기능을 물려받고, 자식 생성자에서 `super()`로 부모 생성자를 호출함.
    - 오버라이드로 부모 메서드를 자식에서 재정의하고, 다중 상속의 개념을 확인함.

4. **모듈 사용 맛보기** — 직접 만든 `.py` 파일을 모듈로 불러와 함수를 재사용하는 흐름을 실습.
    - `add_sub_module.py`(덧셈·뺄셈), `converter.py`(변환) 모듈을 작성해 `import`로 호출함.

5. **Day04 과제** — 반복문과 클래스를 함께 활용하는 문제 풀이.
    - 1~1000 중 3의 배수 합, 반복문 구구단 출력, 화폐 매수 계산(거스름돈) 문제를 풀이함.
    - `Knight` 클래스 문제에서 생성자로 속성을 초기화하고 메서드(`slash()`)를 정의함.

## 💭 오늘의 회고

1. **배운 점**
    - 함수가 기능 단위였다면, 클래스는 데이터(속성)와 기능(메서드)을 하나로 묶어 객체를 찍어내는 설계도임을 이해함.
    - `self`는 인스턴스 자신을 가리키며, 인스턴스 변수·메소드의 기준점이 됨.
    - 특수 메서드를 재정의하면 출력·비교 같은 기본 동작을 객체에 맞게 바꿀 수 있음.

2. **어려운 점/개선할 점**
    - 인스턴스 변수와 클래스 변수, 인스턴스 메서드와 클래스 메서드의 소속을 헷갈리지 않도록 예제를 반복 실행하기.
    - 캡슐화의 프라이빗 변수(`__이름`) 네이밍과 getter/setter 패턴은 손에 익을 때까지 직접 작성해 보기.

3. **액션 플랜**
    - `Knight` 클래스를 속성·메서드를 추가해 확장하며 생성자와 메서드 정의를 복습하기.
    - 직접 만든 모듈을 다음 수업의 표준 라이브러리·패키지 학습과 연결하기.

4. **함께 나누고 싶은 점**
    - 자식 클래스에서 생성자를 정의하면 부모 생성자가 자동 호출되지 않으므로, `super().__init__()`을 명시적으로 호출해야 함.
