## 📝 오늘 배운 내용 요약

1. **변수와 복합 대입 연산자** — 변수는 데이터를 저장하는 이름으로, `=` 기호는 오른쪽 값을 왼쪽 변수에 할당한다는 의미.
    - 복합 대입 연산자: 기본 연산자와 `=`를 합친 것. `+= -= *= /= %= **=`.
    - 예) `a += 10` 은 `a = a + 10` 과 같음. 숫자뿐 아니라 문자열도 `str1 += "!"` 처럼 누적 가능.
    - **자료형 변환(형변환)**: `int()`(문자열→정수), `float()`(문자열→실수), `str()`(숫자→문자열). 입력값을 계산에 쓰려면 형변환이 필수.

2. **컬렉션 — 여러 자료를 하나의 이름으로 묶는 자료형**

    | 컬렉션 | 생성 함수 | 특징 | 예시 |
    | :-- | :-- | :-- | :-- |
    | 리스트 | `list()` | 추가·수정·삭제 자유, 순서 있음 | `[1, 2, 3]` |
    | 튜플 | `tuple()` | 생성 후 수정 불가(불변) | `(1, 2, 3)` |
    | 세트 | `set()` | 중복 불가, 순서 없음 | `{1, 2, 3}` |
    | 딕셔너리 | `dict()` | 키 + 값 쌍으로 저장 | `{'age': 25}` |

    - 순서가 있어 인덱스로 접근 가능한 컬렉션을 **시퀀스(sequence)** 라 부름 → 리스트, 튜플.
    - **리스트**: 서로 다른 자료형도 한 리스트에 담을 수 있음 (`[273, 32, 103.1, "문자열", True]`).
    - 인덱싱/슬라이싱은 문자열과 동일 — `list_num[0]`, `list_num[-1]`, `li[:3]`.
    - **중첩 리스트**: 리스트 안에 리스트 → `li[-1][0]` 처럼 단계별로 인덱싱.

3. **제어문 — 조건문(if)** — 조건의 참/거짓에 따라 실행 흐름을 분기.
    - `if 조건식:` → 조건식 결과가 `True`일 때만 들여쓴 코드 실행.
    - `if-else`: 조건이 거짓일 때 실행할 코드를 함께 작성. 비교를 한 번만 하므로 효율적.
    - 실전 예) `if money >= pay:` 로 잔액과 요금을 비교해 분기.
    - **포함 연산자 `in` / `not in`**: `1 in [1, 2, 3]` → `True`. 값이 컬렉션 안에 있는지 확인.

4. **실습 과제**
    - **Day01 (자료형 종합)**: ① 홀짝 판별(`num % 2 == 0`) ② 주민번호 슬라이싱으로 생년월일/성별 분리 ③ URL에서 규칙 기반 비밀번호 생성기(`replace`·`format`·`len`·`count` 활용).
