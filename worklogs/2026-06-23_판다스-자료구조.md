# 판다스 자료구조 — 2026-06-23

> 날짜: 2026-06-23 · Subject: 데이터 전처리·시각화 · title: 판다스 자료구조(Series·DataFrame) · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **파이썬 기초 테스트** — 기초 단원 마무리 점검.
    - 튜플 슬라이싱으로 원하는 원소 선택하기.
    - 중첩 딕셔너리(`q6`)에서 `id`·`name`·`age`·과목 점수와 총점을 리스트로 추출.
    - 영화 박스오피스 데이터(`q7`)를 반복문으로 순회하며 항목 출력.

2. **판다스 자료구조 개요** — 분석 데이터를 컴퓨터가 다루기 쉬운 형태로 정리.
    - 판다스의 대표 자료구조는 1차원 배열 **Series**와 2차원 배열 **DataFrame**.

3. **Series(시리즈)** — 데이터가 순차적으로 나열된 1차원 배열.
    - 각 인덱스(index)와 값(value)이 1:1로 대응하며, 인덱스는 데이터의 위치를 나타내는 이름표 역할.
    - 리스트를 Series로 변환하면 인덱스를 지정하지 않은 경우 정수 위치 인덱스(0, 1, 2, …)가 자동 생성.
    - **원소 선택**: 하나/여러 원소 선택, 인덱스 범위 지정(슬라이싱), 정수 위치 인덱스와 인덱스 이름(따옴표) 활용.

4. **DataFrame(데이터프레임)** — 행과 열로 이루어진 2차원 배열.
    - 여러 개의 Series를 모아 구성하며, 각 열이 하나의 Series.
    - 행 인덱스는 하나의 레코드(record), 열 이름은 데이터의 속성을 의미.
    - 예) 주식 종목 데이터 — 행: 각 종목, 열: 회사 이름·종가·거래량 등.

5. **행/열 인덱스 변경** — `index`·`columns` 속성 직접 재할당, 또는 `rename(index=…, columns=…)`.
    - `rename`은 원본을 변경하지 않고 새 객체를 반환(복사 기반).

6. **행/열 삭제 — `drop()`** — `axis=0`은 행, `axis=1`은 열 삭제.
    - 여러 항목은 리스트로 입력, 원본 반영은 `inplace=True`.

7. **선택 — `loc` / `iloc`** — `loc`은 인덱스 이름, `iloc`은 정수 위치 인덱스.
    - 행 선택, 열 선택(대괄호·점 접근), `[행, 열]` 좌표로 원소 선택.
    - 1행·1열이면 Series, 2개 이상 × 2개 이상이면 DataFrame으로 반환.

8. **열 추가** — `데이터프레임["새 열 이름"] = 값 또는 배열`.

## 💭 오늘의 회고

1. **배운 점**
    - Series는 인덱스–값이 1:1로 묶인 구조라 딕셔너리와 비슷하게 생각하면 이해가 쉬움.
    - DataFrame은 결국 여러 Series의 묶음이라, 열 하나를 떼면 Series가 됨을 직접 확인.
    - `loc`(이름)과 `iloc`(위치)의 구분이 선택 작업의 핵심.

2. **어려운 점/개선할 점**
    - `loc`/`iloc`에서 반환 타입(Series vs DataFrame)이 선택 개수에 따라 달라지는 규칙 정리하기.
    - `rename`·`drop`이 원본을 바꾸지 않는다는 점과 `inplace` 옵션 사용 시점 익히기.

3. **액션 플랜**
    - 실제 데이터(CSV)를 불러와 행/열 선택·추가·삭제를 반복 실습하기.
    - 다음 전처리 단계(결측치·인덱싱)에서 `loc`/`iloc`를 다시 활용해 보기.

4. **함께 나누고 싶은 점**
    - 파이썬 기본 자료형(리스트·딕셔너리)에 대한 이해가 탄탄하면 Series·DataFrame 구조가 자연스럽게 연결됨.
