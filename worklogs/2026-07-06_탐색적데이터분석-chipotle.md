# 탐색적 데이터 분석 실습 정리 (Chipotle) — 2026-07-06

> 날짜: 2026-07-06 · Subject: 수학·통계 · title: Chipotle 주문 데이터 EDA 실습 마무리 · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **Chipotle 주문 데이터 EDA 마무리** — 주문 데이터의 구조를 파악하고 분석 질문을 수치로 확인.
    - `order_id`, `quantity`, `item_name`, `item_price`를 중심으로 데이터의 행과 열, 결측 여부, 범주형 변수의 종류를 확인.
    - 아이템별 주문 횟수와 총 주문 수량을 집계해 가장 많이 주문된 메뉴를 파악.
    - `item_price`의 달러 기호를 제거하고 숫자형으로 변환해 주문 금액 분석이 가능하도록 전처리.

2. **주문 단위 분석과 메뉴 가격 탐색** — 행 단위 데이터를 주문·메뉴 단위 지표로 바꾸는 흐름을 실습.
    - 주문별 총 결제 금액을 계산하고, 주문 1건당 평균 결제 금액을 확인.
    - 20달러 이상 결제한 주문을 필터링해 조건 기반 탐색을 연습.
    - 같은 메뉴를 1개만 구매한 기록을 활용해 아이템별 가격을 추정하고 시각화.

## 💭 오늘의 회고

1. **배운 점**
    - EDA는 `head()`, `info()`, `describe()`로 훑는 단계에서 끝나는 것이 아니라, 질문을 세우고 집계·시각화·해석으로 좁혀 가는 과정이라는 점이 더 명확해졌다.
    - 문자열 금액처럼 분석에 바로 쓰기 어려운 컬럼은 전처리 후 자료형을 확인해야 이후 집계 결과를 믿을 수 있다.
    - `groupby()`와 정렬, 필터링을 조합하면 행 단위 데이터에서 주문 단위·메뉴 단위 지표를 유연하게 만들 수 있다.

2. **어려운 점/개선할 점**
    - 같은 데이터라도 어떤 단위로 묶느냐에 따라 해석이 달라지므로, 분석 기준 단위를 먼저 정리하는 습관이 필요하다.
    - 단품 구매 기록만으로 가격을 추정하는 방식이 항상 정확한 것은 아니므로, 예외 케이스(세트 메뉴, 토핑 추가 등)를 함께 고려해야 한다.

3. **액션 플랜**
    - Chipotle 노트북에서 `item_price` 전처리와 주문별 집계 과정을 다시 실행하며 각 단계의 입력·출력을 설명해 보기.
    - 다음 실습(Drinks 데이터셋)에서 재사용할 수 있도록 `groupby()`, `sort_values()`, 조건 필터링 패턴을 정리해 두기.

4. **함께 나누고 싶은 점**
    - 행 단위 주문 데이터를 주문·메뉴·가격 단위로 재구성하는 흐름이 실제 매출 분석 리포트의 뼈대와 비슷하다는 감이 잡힌 시간이었다.
