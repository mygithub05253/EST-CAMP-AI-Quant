# 수학·통계 기초와 EDA 실습 마무리 — 2026-07-03

> 날짜: 2026-07-03 · Subject: 수학·통계 · title: numpy·선형대수·데이터 분석 이해·EDA 실습 마무리 · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **numpy 배열 연산 복습과 확장** — 수치 계산을 벡터화하는 기본기를 정리.
    - 다차원 배열 생성, 자료형 지정, 인덱싱·슬라이싱으로 필요한 값을 조회하는 흐름을 실습.
    - 전치, 배열 크기 변형, 벡터화 연산, 브로드캐스팅, 축(axis)에 따른 집계를 복습.
    - `inf`와 `nan`처럼 계산 중 자주 만나는 특수값을 확인하고, 결과 해석 시 주의할 점을 정리.

2. **선형대수 기초** — 퀀트 모델링에 필요한 벡터 감각 만들기.
    - 스칼라와 벡터의 차이를 구분하고, 벡터의 크기와 단위 벡터 계산을 연습.
    - `zeros`, `ones`, `arange`, `linspace` 등 배열 생성 함수를 활용해 실습 데이터를 빠르게 구성.
    - 수식으로만 보던 선형대수 개념을 numpy 배열 연산으로 연결해 이해.

3. **데이터 분석의 이해와 통계적 사고** — 분석 절차와 판단 기준 정리.
    - 데이터 과학 프로젝트의 진행 과정, 기술 통계와 추론 통계의 역할을 구분.
    - 변수와 척도, 귀무가설·대립가설, 유의수준과 p값을 중심으로 가설검정 절차를 정리.
    - 인지적 편향과 분석가의 주관적 판단이 결과 해석에 미치는 영향을 확인.

4. **Chipotle 주문 데이터 EDA** — 실제 데이터로 분석 흐름 실습.
    - 데이터 파악, 전처리, 속성 탐색, 시각화 순서로 EDA 과정을 진행.
    - 가장 많이 팔린 메뉴 10개와 주문 1건당 평균 결제 금액을 확인.
    - 정리한 분석 결과를 그래프로 표현하며 데이터 탐색 결과를 전달 가능한 형태로 만들기.

5. **확률·평균 실습 산출물 정리** — 과제와 프로젝트 노트북 저장.
    - 산술평균·기하평균·조화평균 비교 실습으로 평균의 의미 차이를 확인.
    - 주사위 합 확률 시뮬레이션을 통해 시행 횟수가 커질수록 경험적 확률이 이론값에 가까워지는 흐름을 관찰.

## 💭 오늘의 회고

1. **배운 점**
    - numpy의 벡터화와 브로드캐스팅을 이해하면 반복문보다 간결하고 빠르게 데이터를 다룰 수 있다는 점을 체감.
    - 기술 통계는 현재 데이터를 설명하고, 추론 통계는 표본을 통해 모집단을 판단한다는 차이가 더 명확해짐.
    - EDA는 단순히 그래프를 그리는 작업이 아니라 데이터 구조를 이해하고 질문을 좁혀 가는 과정이라는 점을 확인.

2. **어려운 점/개선할 점**
    - `axis=0`과 `axis=1`의 방향은 여전히 순간적으로 헷갈릴 수 있어 작은 배열 예제로 반복 연습 필요.
    - 가설검정의 p값은 기계적으로 해석하지 않고, 유의수준과 분석 맥락을 함께 봐야 함.
    - EDA 결과를 설명할 때 수치와 그래프를 어떤 순서로 제시해야 설득력이 생기는지 더 연습해야 함.

3. **액션 플랜**
    - Chipotle EDA 노트북을 다시 실행하며 전처리 단계와 시각화 코드를 스스로 설명해 보기.
    - 평균 비교·확률 시뮬레이션 노트북에 결과 해석 마크다운을 보강하기.
    - 다음 수업 전까지 가설검정 용어(귀무가설, 대립가설, p값, 유의수준)를 예시와 함께 복습.

4. **함께 나누고 싶은 점**
    - numpy 배열 연산, 통계 개념, EDA가 따로 떨어진 내용이 아니라 “데이터를 계산하고, 요약하고, 해석하는 흐름”으로 이어진다는 점이 인상적이었음.
