    - `GOOGL.csv`(구글 주가) 데이터로 랜덤워크 여부를 시각적으로 확인하고, 차분(differencing)을 적용해 정상성으로 바뀌는 과정을 실습.
2. **위젯 판매량 데이터 실습** — `widget_sales.csv`로 확률보행 프로세스를 다른 도메인 데이터에서도 확인.
    - 주가 데이터와 마찬가지로 차분 후 정상성이 확보되는지 비교.
3. **이동평균 프로세스 단원 도입** — 다음 학습을 위해 `7.이동평균프로세스.ipynb`를 열어 개념 도입부까지 확인.

## 💭 오늘의 회고

1. **배운 점**
    - 확률보행은 "다음 값 = 이전 값 + 랜덤 노이즈"로만 결정되어, 과거 패턴으로 미래를 예측할 수 없다는 점을 데이터로 직접 확인했다.
    - 주가처럼 예측이 어려운 데이터의 특징이 왜 그런지 이론과 실습을 연결해 이해했다.
2. **어려운 점/개선할 점**
    - 정상성 검정(ADF 검정 등) 결과 해석이 아직 익숙하지 않다.
3. **액션 플랜**
    - ADF 검정 통계량·p-value 해석 방법 복습.
    - 확률보행 vs 정상 프로세스 구분 기준을 스스로 정리해보기.
4. **함께 나누고 싶은 점**
    - GOOGL 주가와 위젯 판매량처럼 성격이 다른 두 데이터에서 똑같이 확률보행 패턴이 나타나는 게 흥미로웠다.
