# 📝 worklogs — 작업/학습 기록 로컬 미러

노션 TIL·작업 기록을 **레포에도 보관**하는 폴더입니다. 노션(원본/공유) ↔ 로컬(백업/포트폴리오) 1:1 미러.

## 폴더 규칙
```
worklogs/
├── 2026-06-16_OT-환경세팅.md
├── 2026-06-17_01-python-기초.md
└── ...
```
- 파일명: `YYYY-MM-DD_주제.md` (KST)
- 노션 TIL DB의 한 행 = worklogs의 한 파일 (양방향 동일 내용)

## 노션 TIL 양식 (캠프 샘플 `(Sample) 홍길동 (1)` 기준)
- **DB 컬럼**: `날짜` · `Subject` · `title` · `피드백 요청` · `멘토 피드백`
- **본문**: ① 오늘 배운 내용 요약  ② 오늘의 회고

## 작성·동기화
- `til-record` 스킬로 노션 기록 + 로컬 미러를 동시에 생성한다.
- `bootcamp-worklog` 스킬로 기록 → 미러 → GitHub 푸시까지 한 번에 수행한다.
- 학습 상세 노트는 `learning/<단원>/`, 과제는 `assignments/`에 두고 여기서는 일자별 요약·링크를 남겨도 된다.
