# 판다스 데이터 입출력·탐색 — 2026-06-24

> 날짜: 2026-06-24 · Subject: 데이터 전처리·시각화 · title: 판다스 데이터 입출력 · 데이터 탐색 · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **외부 파일 읽기 개요** — 다양한 포맷의 외부 데이터를 데이터프레임으로 변환.
    - 판다스는 `csv`·`json`·`html`·`excel`·`sql` 등 여러 포맷을 읽는 `read_*` 함수 제공.
    - 데이터프레임을 외부 파일로 저장하는 `to_*` 함수도 함께 제공.

2. **CSV 입출력** — `read_csv("경로")`로 쉼표 구분 텍스트 파일을 읽기.
    - 주요 옵션: `sep`(구분자), `header`(열 이름 행), `index_col`(행 인덱스 열), `names`(열 이름 지정), `skiprows`(건너뛸 행), `parse_dates`(날짜→datetime64), `encoding`.
    - 저장은 `to_csv("파일명")`.

3. **Excel·JSON·HTML 입출력**
    - `read_excel()`은 옵션 대부분이 `read_csv()`와 동일, 확장자에 따라 `engine`(xlsx→openpyxl, xls→xlrd) 고려.
    - `read_json()`은 `key:value` 구조의 JSON을 읽음.
    - `read_html()`은 HTML 페이지의 모든 `<table>` 태그를 찾아 데이터프레임 리스트로 반환.
    - 여러 데이터프레임을 하나의 Excel 파일에 시트별로 저장할 때 `ExcelWriter()`와 `sheet_name` 활용.

4. **데이터 탐색 — auto-mpg 데이터셋** — UCI 머신러닝 저장소의 자동차 연비 데이터.
    - `head()`·`tail()`로 앞/뒤 일부 행 확인, `shape`로 (행, 열) 크기 확인.
    - `info()`로 클래스·인덱스·열 자료형·메모리 사용량 등 기본 정보 파악.
    - 판다스 자료형: 정수 `int64` · 실수 `float64` · 문자열 `object` · 시간 `datetime64`.

5. **요약 통계·빈도** — `describe()`로 평균·표준편차·최대/최소·중앙값 등 통계 요약.
    - `count()`(유효 값 개수), `value_counts()`(고유값 빈도) 활용.
    - 통계 함수: `mean`·`median`·`max`·`min`·`std`·`corr`(상관계수).
    - 상관계수: 부호(양/음의 상관), 크기(0.8~1.0 매우 강함 … 0.0~0.2 거의 없음).

6. **판다스 내장 그래프** — 데이터프레임에서 바로 `plot()`으로 시각화.
    - `line`·`bar`·`barh`·`hist`·`box`·`kde`·`area`·`pie`·`scatter`·`hexbin` 종류.
    - 시간 흐름은 인덱스를 x축으로, 산점도(`scatter`)로 두 변수 관계(weight↔mpg 음의 상관) 확인.

## 💭 오늘의 회고

1. **배운 점**
    - 외부 데이터를 읽는 진입점이 `read_csv`/`read_excel`/`read_json`/`read_html`로 일관되어 옵션만 익히면 포맷이 달라도 동일하게 접근 가능.
    - `info()`·`describe()`·`value_counts()` 세 가지만으로 데이터셋의 구조·분포·결측 여부를 빠르게 감 잡을 수 있음.

2. **어려운 점/개선할 점**
    - `read_csv` 옵션(`header`/`index_col`/`names`/`skiprows`)이 많아 실제 파일에 맞춰 조합하는 연습이 필요.
    - `horsepower` 열의 `?` 문자처럼 숫자에 섞인 비정상 값이 자료형을 `object`로 만들 수 있다는 점 주의.

3. **액션 플랜**
    - 다양한 포맷(csv/tsv/xlsx/json)을 직접 읽어 `info()`·`describe()`로 탐색하는 루틴 굳히기.
    - 탐색에서 발견한 결측·이상값을 다음 단계(전처리)에서 정제하기.

4. **함께 나누고 싶은 점**
    - 탐색 단계의 내장 `plot()`만으로도 분포·관계를 빠르게 확인할 수 있어, 본격 시각화 전에 데이터 감을 잡기 좋음.
