# 넘파이 기초 마무리 + 선형대수 기초 시작 — 2026-07-01

> 날짜: 2026-07-01 · Subject: 수학·통계 · title: numpy 기초 마무리 · 선형대수 기초 시작 · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **넘파이(numpy) 기초 마무리** — 배열 연산 심화.
    - 브로드캐스팅: 서로 다른 형태의 배열 간 연산 규칙.
    - 집계 함수: `sum`·`mean`·`std`·`min`·`max`와 `axis` 지정으로 행·열 방향 집계.
    - 정렬·조건 선택: `sort`·`argsort`·불리언 마스킹·`where`.
    - 유니버설 함수(ufunc)로 원소별 고속 연산.

2. **선형대수(linear algebra) 기초 시작** — 퀀트 모델링 수학 토대.
    - 벡터: 크기·방향, 벡터 덧셈·스칼라 곱, 내적(dot product).
    - 행렬: 행렬 곱(`@`·`np.dot`·`matmul`), 전치(`.T`), 단위행렬·역행렬.
    - `numpy.linalg` 모듈: 역행렬(`inv`)·행렬식(`det`)·연립방정식 풀이 개요.

## 💭 오늘의 회고

1. **배운 점**
    - 브로드캐스팅과 `axis` 개념을 잡으니 반복문 없이 배열 연산을 설계할 수 있게 됨.
    - 벡터 내적·행렬 곱이 이후 회귀·차원축소 등 모델링의 핵심 연산임을 이해.

2. **어려운 점/개선할 점**
    - `axis=0/1`의 방향(행 vs 열)이 여전히 헷갈려 예제로 반복 확인 필요.
    - 행렬 곱의 차원 조건(앞 행렬 열 = 뒤 행렬 행)을 도형으로 익혀야 함.

3. **액션 플랜**
    - 선형대수 기초를 이어가며 고유값·고유벡터까지 확장.
    - numpy 집계·선형대수 연산을 실제 주가/재무 데이터에 적용해 보는 연습.

4. **함께 나누고 싶은 점**
    - numpy에서 시작한 배열 연산이 곧바로 선형대수(벡터·행렬)로 이어져 "코드로 하는 수학"의 감을 잡음.
