# 탐색적 데이터 분석 실습 정리 — 2026-07-07

> 날짜: 2026-07-07 · Subject: 수학·통계 · title: Chipotle·Drinks 데이터 EDA 실습 정리 · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **Chipotle 주문 데이터 EDA 복습** — 주문 데이터의 구조를 파악하고 분석 질문을 수치로 확인.
    - `order_id`, `quantity`, `item_name`, `item_price`를 중심으로 데이터의 행과 열, 결측 여부, 범주형 변수의 종류를 확인.
    - 아이템별 주문 횟수와 총 주문 수량을 집계해 가장 많이 주문된 메뉴를 파악.
    - `item_price`의 달러 기호를 제거하고 숫자형으로 변환해 주문 금액 분석이 가능하도록 전처리.

2. **주문 단위 분석과 메뉴 가격 탐색** — 행 단위 데이터를 주문·메뉴 단위 지표로 바꾸는 흐름을 실습.
    - 주문별 총 결제 금액을 계산하고, 주문 1건당 평균 결제 금액을 확인.
    - 20달러 이상 결제한 주문을 필터링해 조건 기반 탐색을 연습.
    - 같은 메뉴를 1개만 구매한 기록을 활용해 아이템별 가격을 추정하고 시각화.

3. **국가별 음주 데이터 EDA** — 국가·대륙 단위 데이터를 바탕으로 상관관계와 집계 분석을 수행.
    - `drinks.csv`를 불러와 `beer_servings`, `spirit_servings`, `wine_servings`, `total_litres_of_pure_alcohol`, `continent` 컬럼을 확인.
    - 결측치 시각화와 `continent` 결측값 대체를 통해 분석 전 데이터 정제 과정을 정리.
    - 수치형 변수의 피어슨 상관계수를 계산하고, 히트맵과 산점도로 관계를 확인.

4. **대륙별·국가별 소비량 비교** — 그룹화 결과를 해석 가능한 지표로 정리.
    - 대륙별 평균 알코올 소비량을 계산하고 막대그래프로 비교.
    - 전 세계 순수 알코올 소비량 상위 10개 국가를 정렬해 확인.
    - 대륙별 비율, `spirit_servings` 통계량, 전체 평균보다 높은 대륙을 비교하는 추가 탐색을 진행.

5. **기초 통계 분석 연결** — EDA에서 통계 검정으로 이어지는 흐름을 확인.
    - 상관계수는 변수 간 선형 관계를 빠르게 확인하는 도구이지만, 인과관계로 해석하면 안 된다는 점을 정리.
    - 아프리카와 유럽의 맥주 소비량 차이를 비교하는 검정 흐름을 통해 EDA 이후의 추론 통계 방향을 확인.

## 💭 오늘의 회고

1. **배운 점**
    - EDA는 `head()`, `info()`, `describe()`로 훑는 단계에서 끝나는 것이 아니라, 질문을 세우고 집계·시각화·해석으로 좁혀 가는 과정이라는 점이 더 명확해졌다.
    - 문자열 금액처럼 분석에 바로 쓰기 어려운 컬럼은 전처리 후 자료형을 확인해야 이후 집계 결과를 믿을 수 있다.
    - `groupby()`와 정렬, 필터링을 조합하면 행 단위 데이터에서 주문 단위·메뉴 단위·대륙 단위 지표를 유연하게 만들 수 있다.

2. **어려운 점/개선할 점**
    - 같은 데이터라도 어떤 단위로 묶느냐에 따라 해석이 달라지므로, 분석 기준 단위를 먼저 정리하는 습관이 필요하다.
    - 상관계수와 통계 검정 결과를 해석할 때 숫자만 보지 말고 데이터 수, 변수 정의, 결측 처리 방식을 함께 확인해야 한다.
    - 시각화 코드는 작성보다 해석 문장을 붙이는 과정이 더 중요하므로, 그래프마다 한 줄 결론을 남기는 연습이 필요하다.

3. **액션 플랜**
    - Chipotle 노트북에서 `item_price` 전처리와 주문별 집계 과정을 다시 실행하며 각 단계의 입력·출력을 설명해 보기.
    - Drinks 노트북의 상관계수 히트맵, 산점도, 대륙별 평균 소비량 그래프에 해석 마크다운을 보강하기.
    - 다음 학습 전까지 `groupby()`, `sort_values()`, 조건 필터링, 결측값 처리 패턴을 작은 예제로 복습하기.

4. **함께 나누고 싶은 점**
    - 오늘 실습은 pandas 조작, 시각화, 통계 해석이 한 흐름으로 이어져서 실제 분석 보고서의 뼈대를 어떻게 만드는지 감이 잡힌 시간이었다.
