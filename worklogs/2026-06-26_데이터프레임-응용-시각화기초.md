# 데이터프레임 응용 + 데이터 시각화 기초 — 2026-06-26

> 날짜: 2026-06-26 · Subject: 데이터 전처리·시각화 · title: 데이터프레임 응용(함수 매핑·그룹 연산) · 데이터 시각화 기초(matplotlib) · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **함수 매핑** — 개별 원소를 특정 함수에 일대일 대응시켜 사용자 정의 연산 적용.
    - 시리즈 원소: `Series.map(매핑함수)` — 원소 개수만큼 리턴값을 받아 같은 크기 시리즈로 변환.
    - 데이터프레임 원소/객체 단위 매핑도 가능.

2. **열 분리** — 한 열에 여러 정보(예: 연월일)가 있으면 연·월·일로 분리.

3. **필터링** — 조건식을 만족하는 원소만 추출.
    - 불리언 인덱싱: 조건식으로 참/거짓 시리즈를 만들어 참인 값만 선택.
    - `isin()`: 특정 값을 가진 행들을 추출.

4. **데이터프레임 합치기**
    - `concat()`: 형태를 유지하며 이어 붙이기.
    - `merge()`: SQL `join`처럼 키(key) 기준 병합(키는 양쪽에 모두 존재해야 함).
    - `join()`: `merge` 기반이되 행 인덱스를 기준으로 결합.

5. **그룹 연산 — `groupby()`** — 분할(split) → 적용(apply) → 결합(combine).
    - 1개/여러 열 기준 그룹화, 집계 함수(`mean`·`sum`·`count`·`size`·`var`·`std`·`first`·`last` 등).
    - `agg()`: 사용자 정의·다중 함수 집계(리스트, `{열:함수}` 딕셔너리).
    - `filter()`: 조건이 참인 그룹만 필터링, `apply()`: 그룹별 함수 매핑.

6. **멀티 인덱스** — 행 인덱스를 여러 레벨로 구현.

7. **데이터 시각화 개요** — 분석 결과를 쉽게 이해·전달하기 위한 표현.
    - 라이브러리: `matplotlib`(기본), `seaborn`(테마·히트맵·카운트플롯), `folium`(지도), `plotly`(인터랙티브), `wordcloud`.
    - 시각화 단계: 라이브러리 불러오기 → x·y 데이터 정하기 → `plot()` 입력 → 그래프 표시.

8. **그래프 종류·기본 그래프**
    - 일변량(연속형: 히스토그램·박스플롯·바이올린·KDE / 범주형: 막대·파이), 다변량(연속형: 산점도·선 / 범주형: 모자이크·트리맵).
    - 범례·격자·눈금·제목 설정, **서브플롯**(`plt.subplot`·`add_subplot`·`plt.subplots`로 figure·axes 반환).

## 💭 오늘의 회고

1. **배운 점**
    - `groupby`의 "분할–적용–결합" 3단계 모델로 집계·변환·필터링을 한 흐름으로 이해.
    - `merge`(키 기준)와 `join`(인덱스 기준)의 차이를 SQL `join`과 연결해 정리.
