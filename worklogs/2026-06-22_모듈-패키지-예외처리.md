# 모듈 · 패키지 · 예외 처리 — 2026-06-22

> 날짜: 2026-06-22 · Subject: Python 기초 · title: 모듈 · 패키지 · 예외 처리 · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **모듈과 모듈 사용** — 함수·변수·클래스를 모아 둔 `.py` 파일을 다른 프로그램에서 불러와 재사용.
    - `import 모듈`, `from 모듈 import 함수`, `from 모듈 import *`의 차이와 사용법을 익힘.
    - 모듈을 직접 만들어 별칭(`as`)으로 불러오는 흐름을 실습함.

2. **표준 라이브러리** — 파이썬에 기본 내장되어 별도 설치 없이 import로 쓰는 모듈.
    - `math`: 수학 관련 상수·함수.
    - `random`: `randint()`·`randrange()`·`random()`·`choice()`·`sample()`·`shuffle()`로 난수와 무작위 추출을 실습.
    - `time`: `time()`·`ctime()`·`sleep()`로 시간 처리.
    - `datetime`: `now()`·`date()`·`time()`·`timedelta()`로 날짜·시간 연산.

3. **패키지·라이브러리·프레임워크** — 모듈을 묶은 단위와 외부 코드 활용 개념.
    - 패키지는 모듈의 집합이며, `pip`/`conda`로 외부 패키지를 설치·삭제함.
    - 라이브러리는 개발자가 호출하는 도구, 프레임워크는 제어의 역전(IoC)으로 프레임워크가 개발자 코드를 호출함을 구분.

4. **예외 처리** — 실행 중 발생하는 오류로 프로그램이 비정상 종료되지 않도록 처리.
    - `try-except`의 기본 구조와 발생 오류·오류 메시지를 받는 형태를 실습함.
    - `else`(예외 없을 때)·`finally`(항상 실행)의 역할과 조합 형태를 익힘.
    - `raise`로 예외를 강제 발생시키고, `Exception`을 상속한 사용자 정의 예외 클래스를 작성함.
    - 오류 종류를 구문 오류(SyntaxError)와 런타임 오류로 구분하고, 조건문 대신 예외 처리를 쓰는 경우와 `pass` 활용을 확인함.

5. **Day05 과제** — 반복문·중첩 자료구조 활용 문제 풀이.
    - 홀수 제곱 리스트, 두 리스트를 딕셔너리로 결합, 행렬(전치) 구성, 중첩 딕셔너리·리스트에서 값 추출 문제를 풀이함.

6. **주소록 프로젝트** — 클래스와 예외 처리를 종합한 미니 프로젝트.
    - 아이디·이름·성별·키·몸무게를 입력받아 주소록에 등록(자료형 변환·중복 처리)하고, 아이디로 정보를 삭제하는 기능을 구현함.

## 💭 오늘의 회고

1. **배운 점**
    - 표준 라이브러리만 잘 활용해도 난수·시간·날짜 처리를 직접 구현하지 않고 해결할 수 있음.
    - 예외 처리는 오류를 숨기는 것이 아니라, 예상 가능한 실패에 대비해 프로그램 흐름을 안전하게 유지하는 도구임.
    - `finally`는 `return`으로 함수를 빠져나가도 실행되므로 자원 정리에 적합함.

2. **어려운 점/개선할 점**
    - `try`·`except`·`else`·`finally`의 조합 가능한 형태와 작성 순서를 헷갈리지 않도록 정리하기.
    - 사용자 정의 예외를 언제 만들고 `raise`할지, 조건문 검증과의 경계를 사례로 익히기.

3. **액션 플랜**
    - 주소록 프로젝트에 검색·수정 기능을 추가하며 예외 처리를 보강하기.
    - 표준 라이브러리(`random`·`datetime`)를 다음 데이터 분석 학습에서 다시 활용해 보기.

4. **함께 나누고 싶은 점**
    - 모든 오류를 `try-except`로 감싸기보다, 조건문으로 미리 검증할 수 있는 경우와 예외로 처리할 경우를 구분하면 코드가 더 명확해짐.
