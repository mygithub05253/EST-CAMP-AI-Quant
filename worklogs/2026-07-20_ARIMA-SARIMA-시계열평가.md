# ARIMA·SARIMA 모델링과 시계열 평가 — 2026-07-20

> Subject: 시계열 분석 · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **비정상 시계열의 ARIMA 모델링** — `ARIMA(p, d, q)`에서 정상성을 확보하는 최소 차분 횟수가 `d`가 된다는 점을 실습했다.
    - 존슨앤드존슨 분기별 EPS는 2차 차분 후 정상성을 확보했고, AIC와 잔차 진단을 거쳐 `ARIMA(3, 2, 3)`을 선택했다.
    - 계절 단순 예측의 MAPE `11.56%`와 비교했을 때 ARIMA의 MAPE는 `1.71%`였다.
    - 위젯 판매량은 1차 차분 후 `ARIMA(3, 1, 3)`으로 롤링 예측했으며, MAE는 평균 예측 `14.22`, 마지막 값 예측 `1.82`, ARIMA `1.57`이었다.
2. **계절성을 반영한 SARIMA 모델링** — `SARIMA(p, d, q)(P, D, Q)m`에서 계절 차수와 주기 `m`의 의미를 학습했다.
    - AirPassengers 144개월 데이터를 STL로 추세·계절·잔차로 분해하고 일반 차분과 계절 차분을 비교했다.
    - 월 주기 `m=12`를 적용한 `SARIMA(2, 1, 1)(1, 1, 2, 12)`의 MAPE는 `2.86%`로, 단순 계절 예측 `9.99%`와 `ARIMA(11, 2, 3)`의 `3.85%`보다 낮았다.
3. **시계열 평가 문제 풀이** — 정상성 검사, ACF·PACF 차수 식별, 롤링 예측을 한 흐름으로 적용했다.
    - `test_1.npy`는 1차 차분 후 정상성을 확보했다.
    - `test_2.npy`는 1차 차분 후 AR(2)로 식별해 원 시계열을 `ARIMA(2, 1, 0)`으로 해석했다.
    - bandwidth 데이터의 마지막 168 timesteps를 차분 기반 `ARMA(2, 2)`로 예측했다. 차분 구간 MSE는 `1.769`, 원 단위 복원 후 MAE는 `8.412`였다.
4. **기초 노트북과 학습 자산 정리** — 시간 시각화, 시계열 분해, 베이스라인, 확률보행, MA 프로세스 노트북을 다시 실행하고 AR·MA·ARMA·ARIMA·SARIMA 참고 이미지와 항공 승객 CSV를 연결했다.
    - 저장된 노트북 기준으로 비어 있지 않은 코드 셀은 모두 실행 기록이 있으며 `error` 출력은 0건이었다.
    - 이는 저장된 출력 검사 결과이며 깨끗한 커널에서 처음부터 전체 재실행한 검증은 아니다.

## 💭 오늘의 회고

1. **배운 점**
    - 모델 차수 선택은 ACF·PACF나 AIC만으로 끝나는 것이 아니라, 잔차가 백색소음인지 확인하고 베이스라인보다 실제 오차가 줄었는지까지 확인해야 한다는 흐름을 정리했다.
    - 비계절 차분 `d`와 계절 차분 `D`를 분리해 생각하면 ARIMA에서 SARIMA로 확장되는 구조를 이해하기 쉬웠다.
2. **어려운 점/개선할 점**
    - ARIMA·SARIMA 차수 조합 탐색의 계산 비용이 크고, 롤링 예측에서는 데이터 구간과 이전 셀의 상태를 정확히 관리해야 했다.
    - `10.비정상시계열예측.ipynb`의 연습문제 데이터 슬라이싱 한 곳과 `11.계절성고려하기.ipynb`의 첫 차분 ADF 검사 한 곳은 깨끗한 커널 재실행 전에 의도와 변수를 다시 확인할 필요가 있다.
3. **액션 플랜**
    - 위 두 재현성 점검 항목을 확인한 뒤 깨끗한 커널에서 전체 실행하고, 예측 신뢰구간과 시계열 교차검증도 추가해 본다.
4. **함께 나누고 싶은 점**
    - 계절성이 명확한 항공 승객 데이터에서는 계절 구조를 직접 반영한 SARIMA가 비계절 ARIMA와 단순 계절 예측보다 낮은 MAPE를 보였다.
