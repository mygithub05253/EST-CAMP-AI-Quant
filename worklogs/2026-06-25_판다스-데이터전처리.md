# 판다스 데이터 전처리 — 2026-06-25

> 날짜: 2026-06-25 · Subject: 데이터 전처리·시각화 · title: 판다스 데이터 전처리(결측치·중복·표준화·정규화) · 피드백 요청: 아니오

## 📝 오늘 배운 내용 요약

1. **데이터 전처리 개요** — 분석 정확도와 결과 품질은 전처리에 좌우.
    - 누락·중복·이상 데이터를 점검·제거하고 분석 목적에 맞게 가공하는 과정.

2. **누락 데이터 처리** — 비어 있는 값은 보통 `NaN`(Not a Number)으로 표시.
    - 탐지: `isnull()`/`isna()`(누락이면 True), `notnull()`/`notna()`(유효면 True).
    - 제거: `dropna()` — `subset`(특정 열 기준), `how`("any" 하나라도 NaN / "all" 모두 NaN).
    - 치환: `fillna()`(평균·최빈값 등으로 대체), `ffill()`(앞 값)·`bfill()`(뒤 값).
    - `NaN`으로 표시되지 않은 누락(`0`·`-`·`?`)은 `replace()`로 `np.nan` 변환 후 처리.

3. **중복 데이터 처리**
    - 확인: `duplicated()` — 이전 행과 중복이면 True(boolean 시리즈 반환).
    - 제거: `drop_duplicates()` — `subset`으로 기준 열 지정 가능.

4. **데이터 표준화** — 같은 의미의 값을 일관된 형태로 통일.
    - 단위 환산, 대소문자 통일, 자료형 변환(`dtypes` 확인 후 숫자형으로 변환 등).

5. **구간 분할(binning)** — 연속형 데이터를 일정 구간으로 나눠 범주형으로 변환.

6. **더미 변수·원핫인코딩** — 범주형 데이터를 0/1 벡터로 변환해 머신러닝이 인식 가능하게.

7. **정규화(normalization)** — 열마다 다른 값 범위를 0~1(또는 -1~1)로 맞춰 분석 왜곡 방지.
    - 최소-최대 정규화: `(x - min(x)) / (max(x) - min(x))`.

## 💭 오늘의 회고

1. **배운 점**
    - 전처리는 "탐지 → 제거/치환 → 표준화 → 변환/정규화" 순서로 흐름을 잡으면 길을 잃지 않음.
    - `dropna`로 무작정 버리기보다 `fillna`·`ffill`/`bfill`로 살릴 수 있는 데이터를 최대한 활용해야 함을 이해.

2. **어려운 점/개선할 점**
    - 누락이 `NaN`이 아닌 `?`·`-`·`0`으로 위장된 경우를 먼저 `replace`로 표준화해야 한다는 점이 실수하기 쉬움.
    - `fillna` 대체값(평균 vs 최빈값) 선택 기준을 데이터 성격에 맞게 판단하는 연습 필요.

3. **액션 플랜**
    - Day08 누락데이터처리·연습문제로 결측·중복 처리를 반복 실습.
    - 정규화한 데이터를 이후 머신러닝 입력으로 연결해 효과 확인.

4. **함께 나누고 싶은 점**
    - 정규화는 값의 크기 차이가 큰 변수들을 같은 출발선에 세우는 작업이라, 모델이 특정 변수에 치우치지 않게 하는 핵심.
